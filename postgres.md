Не проблема, давай по шагам.

**1. Заходим внутрь контейнера с Postgres:**

```bash
docker exec -it demo-postgres psql -U postgres
```

Разбираю команду: `docker exec -it` — зайти внутрь работающего контейнера в интерактивном режиме, `demo-postgres` — имя контейнера (у тебя оно именно такое, судя по более раннему выводу `docker compose ps`), `psql -U postgres` — запустить psql от имени пользователя `postgres`.

Если попросит пароль — это пароль суперпользователя Postgres на твоём стенде (обычно задан в `.env` файле проекта `ad-opa-demo`, переменная типа `POSTGRES_PASSWORD`).

**2. Если зашло — увидишь приглашение вида:**
```
postgres=#
```

Это значит, ты внутри psql и можешь вводить SQL-команды или psql-мета-команды (те, что начинаются с `\`).

**3. Смотрим список БД:**
```sql
\l
```
Нажми Enter — выведется таблица со списком баз. Если список длинный и не помещается на экран — psql покажет постранично, листай пробелом, выйти из просмотра — клавиша `q`.

**4. Выполняем нужные команды (создание пользователя и права)** — просто печатаешь SQL-команды, которые я давал раньше, каждую с `;` в конце, и жмёшь Enter.

**5. Выйти из psql:**
```sql
\q
```
